# Atri Desktop

Atri 的 Windows 桌面程序，连的是新的 Atri（atri-self，源码仓库 `kf15884/Atri`）。

> 个人项目。旧 Koishi / HDS 那一套（对话框镜像、0.3 本地观察、服务器插件）在 0.5 去掉了，要用旧版看 git 历史（`e019176`、`a9c6a9b`）。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 自动连接 | 一打开就用 Windows 自带的 ssh 和一把专用钥匙，建一条到服务器桌面入口的隧道，断了自动重连。服务器上的专用账号只能转发到桌面入口，不能登录、不能执行命令（服务器脚本 `deploy/desk-account.sh`）。 |
| 聊天 | 对话框里是你和她的私聊（QQ 上的、桌面上的都在，标来源）；你在桌面说的她只回在桌面；能发图（拖进来、粘贴截图）；她在想时显示“在想……”；本地加密存最近 500 条。 |
| 立绘和提示 | 一张普通图片当立绘，她说话时冒气泡；新消息在右下角弹一张小卡片（不用 Windows 通知）；可以开机自启。 |
| 一起看番 | 截你选的窗口，本地挑帧，用你自己填的看图 / 听的线路看和听，只把文字交给她。见 [一起看番](docs/一起看番.md)。 |
| 日语识别（可选） | `asr/`：本机的 Whisper small，一起看番“声音”可以切成它（不花钱，只出日语原文）。 |

## 目录

| 路径 | 用途 |
| --- | --- |
| `app/` | Electron 程序（0.5.0） |
| `asr/` | 本机日语识别配套（0.1.0） |
| `test/` | `node test/*.cjs`：自动连接、聊天、一起看番的测试（不连真的服务器和模型） |
| `docs/` | 一起看番说明、借鉴来源 |

## 开发

```bash
cd app
npm install
npm start
```

需要 Windows 10/11 自带的 OpenSSH 客户端（设置 → 应用 → 可选功能）。Electron `38.8.6`。

## 安全

- 不存 root 密码；专用钥匙只在应用目录，私钥权限只给当前用户。
- 第一次连接时记下服务器指纹，以后变了就不连（设置里可以“忘掉服务器指纹”）。
- 口令、看图和听的密钥、聊天记录都用系统加密存在本机。
- 一起看番时画面和声音只在你电脑和你填的线路之间走。
- 不要上传口令、密钥、聊天记录、服务器地址、立绘私有素材。
