# Atri Desktop 0.3.0 · 本地观察试用版

## 状态与范围

已完成代码、Windows便携打包和隔离回归。维护者已获主机安装、桥接就绪及 Windows 画面可见的阶段回执；声音、复杂识别质量、GPU时延和观察同步仍需独立验收。不是“整集视频理解已验收”。

0.3保留0.2桌面聊天，新增选定窗口/屏幕的顺序抽样、最多6格自适应分镜、本地视觉服务、本地ASR可选接口、120秒内存缓存、格子局部回看、显式文字同步。

**本包不含模型权重、Ollama安装器或ASR服务。先跑通纯画面，再考虑声音。** 不用第二台服务器跑本地视觉，不改HDS人格/记忆，不使用云端视觉Key。

## 1. Windows先准备本地视觉

安装官方Ollama（https://ollama.com/download），运行本地服务。PowerShell执行：

```powershell
ollama pull qwen2.5vl:3b
```

模型需要下载，请自行确认网络、磁盘与模型许可。地址/模型名默认如下：

- 视觉服务：http://127.0.0.1:11434/v1
- 模型：qwen2.5vl:3b

这是可替换的OpenAI兼容本地视觉接口。若已有其他本地服务，填写实际的回环地址和模型名；不接受localhost别名、局域网或云端地址，不跟随HTTP重定向。务必确认服务后端也使用本地模型，而不是转发云端。

RTX4070 Laptop 8GB建议先用3B模型，30秒一轮；这里没有对该电脑作显存、速度或并发保证。视觉与可选ASR在程序内顺序请求，但各服务可能保留模型显存；仍需控制模型常驻或让ASR用CPU，不能保证8GB同时容纳两个服务。首次模型加载可能较慢，本轮90秒超时会如实失败，不上传假观察。

## 2. 更新主机插件（需要同步文字时）

若只试本地观察，可先不更新服务器并保持“允许向HDS同步观察文字”关闭。

要同步文字，主机需core >=0.2.27 <0.3.0；当前参考包为core0.2.29/HDS1.0.1-rc58.atri.1。先备份：

```bash
atri-memorybackup run
atri-memorybackup verify
```

将本目录的插件tgz、install-atri-desktop.sh、uninstall-atri-desktop.sh上传到主机同一目录。升级时先在Koishi控制台停用旧atri-desktop实例，释放5150，再执行：

```bash
bash install-atri-desktop.sh
```

安装器离线安装，含ws8.22.0，检查core、端口和服务用户加载权限，失败恢复旧代码/package.json/vendor。备份位于/opt/hds-interlude/.atri-desktop-backups/。不运行npm、不改koishi.yml、不重启服务、不触碰数据库；不改package-lock，后续npm install/npm ci需另行协调锁文件，不能直接假定锁文件同步。

控制台重新启用原实例，不重复添加。首次安装才添加atri-desktop并填token。已有token可以继续使用，脚本生成的随机值仅作首次配置候选；不要把token发到聊天。/adesk核对0.3.0与core扩展。本机与插件token须一致。

## 3. 启动Windows便携版

解压Atri-Desktop-0.3.0-win32-x64.zip，运行Atri Desktop.exe。未签名，先校验本包，按自己的安全策略决定是否运行。

既有连接/立绘设置仍使用同一应用数据位置，不随本包携带。SSH隧道继续包含：

```powershell
ssh -N -o ExitOnForwardFailure=yes -L 15140:127.0.0.1:5140 -L 13080:127.0.0.1:3080 -L 15150:127.0.0.1:5150 root@YOUR_SERVER_HOST
```

## 4. 先做纯本地画面验收

1. 对话框或托盘打开“本地观察 / 一起看番”。刷新来源，优先选播放器窗口。
2. **不要先勾声音或文字同步**。确认本地模型地址/名称，30秒一轮，点击开始。
3. 播放普通测试视频，等本轮分镜与文字。选定窗口不可捕获、黑屏、关闭或最小化不可取图时会停止并报错，不退回抓整个屏幕。来源标题发生变化也会停止，防止窗口句柄被另一窗口复用；重新选择即可。
4. 点击某格“回看”，只在仍保留的120秒缓存内细看；单次回看范围最多30秒，只留在本地，不自动同步。
5. 停止并清缓存；也可Ctrl+Alt+O、托盘停止、关闭观察窗或退出程序。

采集约1帧/秒，不是连续录像；选帧按小图HSV变化加权，每区间从3个候选中挑清晰帧。它借鉴分镜阅读机制，不是完整移植DSH算法。快速动作、闪现字幕可能漏掉。没有独立OCR引擎，字幕依赖视觉模型实际读到的内容。

时间是“本次观察会话经过时间”，不是播放器实际进度。不会自动理解快进、回退、暂停或换集；发生这些操作请停止后重新开始，避免把两个时间轴混在一起。不预下载全片，不做全片概览，不提前看结尾。

## 5. 再验收文字同步

先在QQ或桌面正常和Atri聊一句，让core确定本人故事/参与者，再开始观察并勾“允许向HDS同步观察文字”。

仅观察文字与覆盖范围经已认证WS发送；原始图片、音频、窗口标题、模型地址不发给主机。文字可能随HDS请求发往其现有模型供应商，开启前请确认来源没有隐私内容。

服务器只暂存最新文字，120秒过期，按连接、观察会话、序号及本人故事隔离。停止/断线清除，重连不重放旧观察。不向聊天历史追加假用户消息，不直接写HDS数据表，也不额外触发advance或强制Atri说话。

观察显示“服务器临时缓存已接收”只说明缓存接受；接着正常问一句相关话题，HDS才有机会在本人回合通过core取得资料。它可能不用资料或不提及。不能把缓存接受、模型生成、剧情提交、QQ送达当成一回事。旧0.2插件不支持观察协议，会报未就绪而不是静默假成功。

## 6. 可选：电脑播放声音（实验性，需Windows验收）

默认关闭，不请求麦克风。Windows系统回环可能包含其他应用声音，**不是只录选定窗口**。关掉其他播放声音的应用后再试。

可使用本仓库 asr/ 中的独立日语识别配套（便携运行包另行提供，模型字段填 small），或另行准备真正本地的OpenAI兼容ASR服务，支持multipart WAV、POST /v1/audio/transcriptions；模型名填服务实际支持的名称，界面SenseVoiceSmall只是默认提示，不代表已经安装。服务须能返回text，最好有segments。未准备好就保持关闭，不影响纯画面观察。

程序将系统音转为16kHz单声道PCM/WAV，只请求回环ASR地址，然后把ASR文字作为不可信参考交本地视觉模型。并非声线/音乐/情绪理解。ASR失败退回画面，回环不支持时明确提示；不会改用麦克风或云端。

## 边界与清理

- 默认不持久化原始画面/音频/观察文字；程序内只保留约120秒原始缓存、最近4轮结果。停止清除这些内存引用；不承诺覆盖操作系统交换文件、崩溃转储或外部模型服务日志。
- Electron取图API会枚举同类窗口/屏幕的缩略图，仅选定项进入识别与滚动缓存，其余枚举项立即丢弃。刷新来源会在本机显示来源缩略图；不要在他人旁边展示敏感窗口。选择整个屏幕会额外确认。
- 部分受保护视频可能黑屏；不会绕过内容保护。
- 本地端点只做回环限制；若你把本地端点配置为云转发，其后续行为不在程序控制范围。
- 回退：先停用并删除实例再执行uninstall脚本；数据库和聊天镜像文件保留。要回到0.2，重新安装保留的0.2包，不恢复旧数据库。
