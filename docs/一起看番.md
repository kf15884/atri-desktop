# Atri Desktop 0.4 · 和 Atri 一起看番

0.4 新加的“和 Atri 一起看番”连的是**新的 Atri（atri-self）**，不是旧的 Koishi/HDS。旧版的立绘、对话框、本地观察（0.3）原样保留，托盘菜单里改叫“本地观察（旧版 HDS）”；`plugin/` 没有改动。

## 它做什么

1. 你选播放器窗口，填番名和第几集（没填会先用窗口标题，你确认一下）。
2. 程序在你电脑上每秒截 2–6 帧（默认 4），按和 Atri 服务器看视频同一套规则挑帧：
   - 镜头切换；
   - 换了一句字幕（看 8×6 分块里变得最厉害的那块）；
   - 画面变完、稳定下来的那一帧；
   - 一直在动时隔 3 秒补一张，30 秒兜底；
   - 门槛按画面的底噪自动定。
3. 每 10 秒（或“实时”：攒够 3 个新画面就交，最快 5 秒）把这一段拼成一张图交给**你自己填的看图线路**。
   - 拼图最多 12 格、3 列，每格下面标“#序号 时间”；
   - 可选：底部字幕条按原分辨率单独一张，让模型照抄；
   - 可选：角色参考图，Bangumi 头像加编号。
4. 看图模型按 Atri 给的格式写一段文字（场景、出场的人、发生的事、字幕原文、这段值不值得说），程序**只把这段文字和 token 用量**交给 Atri。
5. 画面十几秒不动就当暂停，不交、不计播放时间；关窗口、点停止就结束，Atri 会把这一集整理成她的经历。

## 隐私和边界

- 截图只在内存里，拼好交完就丢；不存盘。
- 看图密钥和 Atri 口令用系统加密存在这台电脑上（`together.json`），不交给 Atri。
- 交给 Atri 的没有图片、窗口标题、看图地址和密钥。
- 选“整个屏幕”会再确认一次；受保护的视频可能黑屏，不绕过。
- 看图线路收到的是你的画面，用哪家由你决定；Atri 地址只接受本机隧道口（`http://127.0.0.1:端口`），看图地址只接受 `https://` 或本机 `http://127.0.0.1`，都不跟随重定向。
- 这不是完播证明：快动作可能漏，字幕和人可能认错；时间是“从几分开始 + 播放的时长”估算的，快进、换集请停止后重新开始。

## 设置

1. 服务器：`/etc/atri/atri.env` 填 `ATRI_DESK_TOKEN`（`openssl rand -hex 24`），重启 atri-self。
2. SSH 隧道加 `-L 15160:127.0.0.1:5160`。
3. 托盘 →“和 Atri 一起看番…”→ 设置：
   - Atri 地址 `http://127.0.0.1:15160`，口令同上；
   - 看图地址、模型、密钥和服务器“看”用的一样（例如 DeepSeek 官方）；
   - 单价填了就能看到大概花了多少。
4. 先点“试一下连 Atri”，能看到番单就是通了。

## 测试范围

- 已运行：挑帧 / 交图节奏 / 暂停 / 提示词 / 地址限制 / 看图与 Atri 接口的本机假服务测试（`node test/together.cjs`）；Chromium 里用合成画面跑通了整个观看窗口（截帧 → 挑帧 → 拼图 / 字幕条 / 角色参考图 → 交出）。
- 没运行：Windows 实机截图、真实看图模型的识别质量和费用、真实 Atri 服务器端到端、Electron 打包。
