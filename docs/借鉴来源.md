# 分镜阅读设计参考

参考仓库：https://github.com/SAOS-3624/dsh-video-storyboard
核对基线：2a6fdc6cb22190606f54a20887632ab63212a0f0（package 0.3.0，MIT，SAOS-3624）。

借鉴：顺序窗口避免剧透；基于变化的非均匀采样；候选清晰帧；编号格子与时间范围；按需局部回看；观察覆盖范围不等于完整观看。

本版为面向Electron桌面流的独立实现，没有直接打包该项目源码或文档图片。算法不是逐字节移植：目前是1fps观察流上的HSV变化加权分区，不含其完整的切点检测、台词密度分配、音量包络图、整片下载与高清直链zoom。格子回看限于本地缓存，文字只通过core临时资料进入HDS。

不套用其“一图384 tokens”的宿主特定成本结论；本地模型速度和资源占用须实机测量。模型权重、Ollama、ASR服务由用户按各自许可自行安装。
