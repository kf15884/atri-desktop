# koishi-plugin-atri-desktop 0.3.0
本人QQ私聊的桌面镜像 + 本地观察文字临时通道。依赖 atri-core >=0.2.27 <0.3.0（API1），身份取自core。先沿用0.2聊天验收，再单独启用观察。

- 图片与声音只交桌面设置中的回环地址本地模型；向主机发送的只有用户选择同步的观察文字和覆盖范围。
- 观察文字按活动WS连接、会话代际、递增序号、故事/参与者绑定；120秒过期，停止/断线清除。不持久化原始观察，不直接写HDS表，不伪造用户输入，不主动触发advance。
- core仅在正常的本人叙事回合提供临时资料；缓存接受不等于HDS已消费或事实成立。工具结果不改人设，不自动写长期记忆。
- 保留before-send后镜像、图片内联、取消不镜像、/adesk管理。
