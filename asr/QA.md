# QA — 日语识别配套包 0.1.0

## 已完成

- 8 项服务测试通过：multipart/WAV 协议、拒绝错误语言/旧模型名/音频URL、WAV 格式/长度、静音、固定日语转写参数、CPU 参数、真实 HTTP 健康/识别/繁忙/Host/Origin/体积限制。
- 真实 Whisper small 固定权重 + CPU/int8 + 本地 HTTP，通过未修改的桌面 0.3.0 transcribe 函数读取公开日语语音的前20秒，返回日语和4个有效时间段。
- 样本来自国立国语研究所 CSJ 公开样本。对照参考文本，正文能识别，但末尾“三分法/藤崎”出现错字/人名误识；不声明逐字准确，更不把演讲样本当成番剧多人对白验收。
- 静音测试返回空文本；VAD/阈值只能减少幻觉，不保证音乐/背景音绝无误识。
- 现有 desktop 0.3.0 observation 回归通过：顺序采样、HTTP/ASR契约、停止/迟到代际隔离、故事/序号/TTL等。
- 模型 model.bin 与 Hugging Face 固定提交的 LFS SHA256 一致：3e305921506d8872816023e4c273e75d2419fb89b24da97b4fe7bce14170d671。
- Windows 23 个官方 PyPI wheel 共2233项 RECORD 内容摘要验证通过；嵌入式 Python 从 python.org 官方 HTTPS 下载，原始下载摘要与文件清单保留。

## 未验收/已知边界

- 当前计算机是 Linux；实际模型测试为 Linux CPU，不是用户 Windows 的性能结果。
- Windows 便携 Python/DLL导入、系统声音回环、与 Ollama 同时运行时的速度、日语番剧准确率、观察文字同步到生产 HDS，均须用户现场确认。
- 未升级现有桌面二进制/主机插件。Node24测试环境中，一次“信号在请求创建前已取消”的 FormData 试验触发 undici 的 ERR_INVALID_STATE 异步异常；该预取消分支不计通过，未据此认定 Electron 内嵌 Node 的表现。Windows 停止/取消期间是否正常需专门验收，出现程序退出应停止音频试用并回报；原有代际隔离回归是模拟取消结果，不替代该实机分支。
- ASR 本身没有持久队列和会话重放；在途的原生推理不能被客户端关闭立即强制终止，只丢弃迟到结果。
- 现版0.3.0按观察轮次切片，没有跨轮重叠去重或真正的实时字幕；主机主要收到融合后的观察摘要而不是全部原文。
- 未联网请求用户模型供应商，未消耗其API额度，未访问或修改用户服务器/数据库。
